Cada **minimundo** (cenário fictício trabalhado em aula) tem sua própria pasta, e novos cenários serão adicionados aqui ao longo do curso.

## 📦 O que tem em cada pasta

Todos os minimundos seguem a mesma organização:

1. **Modelo conceitual:** diagrama entidade-relacionamento (DER) com entidades, atributos e relacionamentos.
2. **Modelo lógico:** tabelas, chaves primárias e estrangeiras derivadas do modelo conceitual.
3. **Código SQL:**
   - **Construção:** `CREATE TABLE` e demais comandos de definição da estrutura.
   - **Inserção de dados:** `INSERT INTO` para popular as tabelas.
   - **Consulta de dados:** `SELECT` para responder às perguntas do exercício.

## ▶️ Como usar

1. Abra a pasta do minimundo desejado.
2. Consulte os modelos conceitual e lógico para entender o cenário.
3. Execute os scripts SQL no seu SGBD, nesta ordem: **construção → inserção → consulta**.
